# Katalog Buku Perpustakaan

Aplikasi desktop sederhana untuk mengelola data buku perpustakaan.
Project ini dibuat menggunakan **Java Swing** dan **Maven** sebagai mini
project mata kuliah Pemrograman Berorientasi Objek (PBO).

## Deskripsi Aplikasi

Katalog Buku Perpustakaan merupakan aplikasi yang membantu pengguna
mengelola data buku, mulai dari melihat daftar buku hingga menambahkan,
mengubah, dan menghapus data. Aplikasi menyediakan pencarian agar data
buku lebih mudah ditemukan.

## Fitur

-   **Menampilkan data buku** dalam bentuk tabel.
-   **Menambah buku** melalui form input.
-   **Mengubah data buku** yang sudah tersimpan.
-   **Menghapus buku** dengan konfirmasi.
-   **Mencari buku** berdasarkan kode, judul, atau penulis.
-   **Mengurutkan data** melalui kolom tabel.
-   **Mengelola status buku**, yaitu Tersedia dan Dipinjam.
-   **Menampilkan ringkasan jumlah buku** berdasarkan status.

## Teknologi yang Digunakan

-   Java
-   Java Swing
-   Maven
-   NetBeans IDE

## Cara Menjalankan Project

1.  Pastikan Java Development Kit (JDK) dan Apache Maven sudah
    terpasang.
2.  Buka NetBeans IDE.
3.  Pilih **File → Open Project**.
4.  Pilih folder project Katalog Buku Perpustakaan.
5.  Tunggu hingga dependensi Maven selesai dimuat.
6.  Jalankan project melalui class utama yang tersedia.
